# Уведомления iOS

Настройка фоновых уведомлений отложена по просьбе пользователя. Сборка 13.0.4 добавляет выбор ботов для быстрых отправок и сохраняет прежний путь подготовки подписи без изменения разрешений APNs.

Разрешение production в предоставленном профиле подтверждено, но установленная подпись, регистрация APNs и серверная настройка для собственного API-приложения не проверены. Доставка в фоне не заявляется.
