# AnchorGram для iOS — первая проверочная сборка

Эта ветка начинает перенос Windows-клиента. Сейчас внесены имя AnchorGram, собственная векторная иконка и изменения сохранения позиции при отправке текста, пересылке и записи голоса. Ручная кнопка перехода вниз сохранена.

Сборка ещё должна пройти на macOS. Факт наличия workflow или успешной проверки синтаксиса не означает, что приложение уже запускается на iPhone.

Пока НЕ перенесены: настраиваемые быстрые направления, извлечение заявок, ограничения групп, проверка дублей, email-фильтр, панель исходящих и тема Aurora. Для них понадобится отдельная адаптация интерфейса и проверка на устройстве после базового запуска. Предпросмотр чата в штатном iOS-клиенте уже доступен удержанием чата в списке; это тоже нужно проверить в собственной сборке.

## Сборка с Windows через GitHub

В своём форке открой Settings → Secrets and variables → Actions.

В Secrets добавь:

- `TELEGRAM_API_ID` — собственный числовой API ID из my.telegram.org/apps.
- `TELEGRAM_API_HASH` — соответствующий API Hash. Не добавляй его в файлы репозитория и сообщения.

В Variables добавь `APPLE_TEAM_ID`: 10 символов Team ID из своего сертификата подписи. Сам сертификат и пароль в GitHub для этой сборки не загружаются.

API ID/Hash идентифицируют приложение. Вход пользователя остаётся по номеру телефона, коду и, если настроен, паролю двухэтапной проверки.

Открой Actions → AnchorGram iOS → Run workflow. Для первой дешёвой проверки можно снять `Build device IPA`: это проверит синтаксис Swift и скрипты. Полная сборка требует оставить галочку. Первая сборка длительная, последующие используют дисковый кеш Bazel при наличии свободного места в кеше GitHub.

После успешной полной сборки скачай артефакт `AnchorGram-unsigned`, распакуй ZIP. Внутри будет `AnchorGram-unsigned.ipa`, затем его нужно подписать в ESign.

## Подпись и запуск — отдельная обязательная проверка

Пока не устанавливай вместо своего основного Telegram. Используется отдельный bundle ID `org.libbro09.anchorgram`.

Telegram использует общий контейнер `group.org.libbro09.anchorgram` и защищённые группы Keychain. Профиль подписи и настройки ESign должны разрешать необходимые entitlements. Произвольный сертификат ESign не гарантирует запуск: без разрешённого App Group штатный код может показать Error 2. Мы не отключаем защиту код-пароля и не заменяем защищённое хранилище обходным способом. Возможности профиля нужно проверить до установки.

В этой первой сборке отключены расширения. Системное меню «Поделиться», виджеты, Siri и уведомления при закрытом приложении здесь не обещаются. Серверные push требуют отдельной корректной настройки APNs и профиля подписи.

## Проверка на устройстве

1. Вход в отдельный клиент по номеру/коду.
2. Обычный чат: отправить текст из середины истории и из самого низа; проверить, что старое сообщение остаётся на месте.
3. Повторить с ответом, пересылкой, голосовым сообщением и темой группы.
4. Проверить, что ручная кнопка вниз работает.
5. Проверить высоту поля ввода при отправке многострочного текста и завершение отправки после ответа сервера.

Результаты этих проверок определят следующий шаг переноса. Полная проверка компиляции и поведения на Windows невозможна: нужны macOS/Xcode и iPhone.
